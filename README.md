# Multi-Agent-Attack-Path-Discovery-and-Mitigation-in-Network-Topologies-
Our project aims to build a multi-agent AI system that discovers attack paths in a network, evaluates their risk, and applies mitigation strategies. Building on our previous work in reinforcement learning for chip design, we are shifting from a static 6x6 grid to a dynamic network graph.
